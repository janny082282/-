# 문제공방 — 로그인 없는 AI 시험 문제은행 (MVP)

강의자료(PDF/PPTX/DOCX/TXT)를 올리고 기출문제·필수 정답 용어를 입력하면, 강의노트 기반 단답형/빈칸형/객관식 문제은행을 생성하는 공개 웹서비스의 **실행 가능한 첫 버전**입니다.

## 기능

- 기출 `질문 → 답: 정답` 형식 입력 시 **원문과 정답을 코드에서 고정** (AI가 수정하지 않음)
- 필수 개념을 **정답으로 지정**하고, 강의자료 근거로 AI 문제 생성 요청
- 자료 파일명·PDF 페이지·PPT 슬라이드 단위로 근거 추적
- AI가 인용한 문장이 실제 추출 자료에 있는지 서버에서 확인하여 `인용문 확인` / `검토 필요` 표시
- 개별 채점, 전체 채점, 오답만 보기, 문제 섞기, 정답 확인
- JSON 다운로드/불러오기, 인쇄, API 키 없이 샘플 문제 체험
- 로그인 없음 / 서버 DB 없음 / 파일은 메모리에서만 처리

> **중요:** 인용문 문자열 일치는 *의미의 진실성*을 보증하지 않습니다. AI가 근거를 잘못 연결할 수 있으므로, 시험 전에는 `출처`를 직접 확인하세요. 이미지형/스캔 PDF는 OCR이 없어서 추출할 수 없습니다. 긴 파일은 일부 페이지가 잘릴 수 있으며 화면에 경고합니다.

## 로컬 실행

Python 3.11 이상을 권장합니다.

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
# Windows에서는 .env.example을 복사하여 .env로 이름을 바꾸세요.
# .env 안의 OPENAI_API_KEY를 자신의 서버용 API 키로 변경
uvicorn app:app --reload
```

웹브라우저에서 `http://127.0.0.1:8000`을 엽니다.

API 키를 설정하지 않아도 `샘플 문제 체험` 버튼과 **기출 원문만 보존하는 기능**은 사용 가능합니다. 강의노트에서 새로운 문제를 AI로 생성하려면 API 키가 필요합니다.

## 배포 예시: Render

1. 이 폴더를 개인 GitHub 저장소에 업로드합니다. `.env` 파일은 절대로 업로드하지 마세요.
2. Render에서 **Blueprint**를 선택하고 GitHub 저장소의 `render.yaml`을 연결합니다.
3. 환경변수 `OPENAI_API_KEY`에 서버 전용 키를 설정합니다.
4. 배포 후 Render가 발급한 URL에서 서비스를 확인합니다.
5. **공개 링크 배포 전에** Cloudflare 등의 외부 레이트리밋, CAPTCHA/Turnstile, 사용량 예산 상한, 모니터링, 개인정보/저작권 안내를 추가해야 합니다.

`render.yaml`의 요금제는 예시이며 서비스의 현재 가격·제한을 확인하세요.

## 안전/개인정보 주의

- **API 키는 반드시 서버 환경변수에만 보관합니다.** 프론트엔드 코드에 넣지 않습니다.
- 파일을 서버에 저장하지는 않지만, 문제 생성 시 **추출된 강의자료 텍스트가 외부 AI API로 전송**됩니다. 사용자는 해당 전송을 알고 있어야 합니다.
- 모델 요청에는 `store: false`를 설정합니다. API 제공자의 별도 보존·처리 정책은 공식 정책을 확인하세요.
- 서버 자체는 문제은행·답안을 저장하지 않습니다. 사용자는 JSON 내보내기로 개인적으로 보관할 수 있습니다.
- 로그인 없는 공개 서비스는 남용·비용 폭증 위험이 있습니다. 현재 인메모리 IP 제한(10분당 4회)은 **단일 프로세스용 최소 방어**로, 실제 공개 운영의 충분한 보호가 아닙니다.
- 학생이 업로드한 강의자료의 저작권을 확인하고, 기본적으로 다른 사람에게 원본이나 생성 문제은행을 공개하지 않도록 운영하세요.
- 인용문을 찾았더라도 AI가 문제와 정답을 잘못 연결할 수 있으므로 출처 확인은 필수입니다.

## 주요 파일

- `app.py` — 파일 추출, 기출 고정, AI 생성, 출처 검증, API
- `static/index.html` — 페이지
- `static/styles.css` — 반응형 UI
- `static/app.js` — 업로드, 시험, 채점, 오답 복습, JSON 입출력
- `render.yaml` — Render 배포 설정
- `tests/test_app.py` — 로컬 자동 테스트

### 현재 구현 범위와 이후 개선점

현재는 **공개용 MVP 코드**이며 배포/운영까지 완료된 것은 아닙니다. 출시 전 사용자 동의 화면, Turnstile, 요금 한도, 장애 모니터링, 개인정보 처리방침, 접근성/모바일 점검이 필요합니다. AI가 지정 정답을 누락하면 경고하지만 자동 재시도·재검증 기능은 후속 버전에서 보강할 수 있습니다.
